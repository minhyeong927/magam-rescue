# 마감구조대

**결정은 우리가. 시작은 당신이.**

할 일을 알고 있어도 무엇부터 해야 할지 몰라 시작을 미루는 대학생을 위한 서비스 소개 홈페이지와 작동하는 웹 체험입니다.

공개 홈페이지: https://minhyeong927.github.io/magam-rescue/

## 실행과 제출

1. 압축 파일을 풀어 `magam-rescue` 폴더를 엽니다.
2. `index.html`을 최신 Chrome, Edge 또는 Safari로 엽니다.
3. 다른 사람에게는 **폴더 전체 또는 ZIP 파일**을 전달하세요. HTML 파일만 보내면 디자인과 기능 파일이 빠집니다.

인터넷, 별도 설치, 로그인, 외부 API, 서버 없이 사용할 수 있습니다. 글꼴도 컴퓨터에 설치된 기본 글꼴을 사용합니다. 입력 내용은 브라우저 내부에 저장하며 파일에는 기록하지 않습니다. 브라우저의 로컬 파일 저장 정책에 따라 저장이 제한될 수 있으며, 이 경우 안내 문구가 표시됩니다.

## 체험하기

- 첫 실행에는 예시 할 일 3개가 들어 있습니다. 상단의 ‘목록 비우기’를 누르면 내 목록을 만들 수 있습니다.
- 할 일 이름만 입력해도 됩니다. 기본값인 ‘마감 없음’을 사용하면 날짜 없이 등록합니다. 날짜 칸은 항상 선택할 수 있으며, 날짜를 고르면 ‘마감 없음’이 자동으로 해제됩니다. 다시 ‘마감 없음’을 체크하면 날짜를 지웁니다. 중요도, 오늘 투자할 시간, 첫 행동은 선택 항목입니다.
- ‘지금 할 일 정해줘’를 누르면 카드 추첨 연출 후 할 일 하나와 첫 행동이 표시됩니다.
- 선택 결과 바로 아래의 ‘바로 5분 시작’로 타이머를 켜고 화면을 채우는 집중 모드로 들어갑니다. 집중 화면에서 이름·첫 행동·최근 메모와 큰 타이머를 함께 봅니다. ‘목록으로 돌아가기’ 또는 Esc로 나가도 타이머는 유지됩니다. 패널의 ‘집중 화면’ 버튼으로 다시 열 수 있습니다. 일시정지, 재개, 새로고침 후 이어받기가 가능합니다.
- 할 일을 고르기 전에도 ‘고르기 맡기고 바로 5분 시작’을 누르면 우선순위대로 하나를 정하고, 추첨 연출 없이 집중 화면과 타이머를 바로 시작합니다.
- ‘다른 일로 바꾸기’는 방금 나온 일을 제외한 나머지 중 우선순위대로 다시 고릅니다. 원래 일은 목록에 남고, 기록한 집중 시간도 유지됩니다. 다른 후보가 없으면 현재 선택과 타이머를 그대로 유지하며 안내합니다.
- 시간이 다 되어도 할 일을 자동으로 완료하지 않습니다. ‘5분 더 하기’로 이어가거나 ‘오늘은 여기까지’로 일을 남겨둡니다. 정말 전체를 끝냈을 때만 ‘일 전체 완료’를 누릅니다.
- ‘오늘은 여기까지’를 누르면 어디까지 했고 다음에 무엇을 할지 선택 사항으로 메모할 수 있습니다. 입력하는 동안 타이머는 멈추고, 창을 닫으면 이어갈 수 있습니다. 최신 메모 하나를 목록과 다음 선택 결과에서 보여주며, 메모 없이 마치면 이전 메모는 유지합니다.
- ‘오늘은 여기까지’는 당일 선택에서만 제외하며 내일 다시 선택할 수 있습니다. 오늘 다시 하고 싶다면 목록의 ‘오늘 다시 하기’를 누릅니다.
- 오늘 시작한 집중 횟수와 실제 타이머 진행 시간을 표시합니다. 각 5분 구간에서 1초 이상 진행했을 때 시작 한 번으로 기록합니다. 일시정지 후 재개·새로고침은 횟수를 중복해서 올리지 않습니다. 타이머 종료 이후 시간은 기록하지 않습니다.
- 집중 시간은 타이머 실행 시간이며 실제 학습 여부를 감지하는 기능은 아닙니다. 백그라운드에서도 정해진 5분까지만 진행됩니다.
- 완료하면 다음 가능한 일을 자동으로 정해 줍니다.
- ‘지금 할 수 없는 일이에요’로 제외하면 다른 일을 정해 줍니다. 제외는 오늘에만 적용하며, 목록의 ‘오늘 다시 하기’ 버튼으로 되돌릴 수 있습니다.
- ‘오늘의 흐름’에서 자동 Big 3와 시작·종료 시간에 맞춘 타임박스를 볼 수 있습니다. 시간이 부족하면 배정하지 못한 분량을 알려 줍니다.

## 우선순위 규칙

1. 완료한 일, 오늘 잠시 제외한 일, ‘오늘은 여기까지’로 남겨둔 일은 선택에서 뺍니다.
2. 마감이 지났거나 3일 안에 마감인 일은 날짜가 빠른 순서로 먼저 고릅니다. 같은 날짜면 중요도를 봅니다.
3. 그 밖의 일은 중요도 점수(높음 40, 보통 20, 낮음 0)에 손대지 않은 날짜 수 × 2점을 더해 비교합니다. 날짜 가산은 최대 30일입니다. 마감이 없어도 같은 기준을 적용합니다.
4. 마지막 타이머 진행일이 있으면 그 날짜부터, 없으면 등록일부터 손대지 않은 기간을 계산합니다.
5. 우선순위가 같을 때만 추첨합니다. 결과에 고른 이유를 보여줍니다.
6. 한 번 정한 일은 전체 완료, 오늘은 여기까지, 잠시 제외, 다른 일로 바꾸기 중 하나를 선택할 때까지 유지합니다. 새 할 일을 추가했다고 진행 중인 일을 갑자기 바꾸지 않습니다.

카드 추첨은 결과를 보여 주는 연출이며, 모든 일을 똑같은 확률로 뽑는 방식은 아닙니다. 애니메이션 건너뛰기와 운영체제의 모션 줄이기 설정을 지원합니다.

첫 행동은 사용자가 적은 내용 또는 유형별로 준비된 문구입니다. 외부 AI가 할 일의 내용을 분석하는 기능은 없습니다.

## 홈페이지 기획

- 방문자: 과제·시험·개인 일정이 겹치고, 선택과 시작을 어렵게 느끼는 대학생.
- 방문자의 궁금증: 내가 지금 무엇부터 하면 되는지, 어떤 기준으로 정해 주는지.
- 핵심 가치: 사용자가 또 다른 계획을 고민하지 않도록 지금 할 일 하나와 작은 첫 행동을 제시.
- AIDA: 첫 화면의 공감 문구 → 문제와 선택 기준 설명 → 사용 과정과 결과 예시 → 실제 체험 버튼.
- 디자인: 종이 플래너의 미색, 검은 글자, 라임색 표시, 주황색 스티커와 편집형 배치.
- 제공 형태: 무료 웹 체험 프로토타입. 사업 확장 시 반복 일정·장기 기록 등 추가 기능의 유료화 가능성을 검토할 수 있으나, 이번 버전에는 결제 기능이 없습니다.

## 발표 때 사용할 기획 의도

마감구조대는 할 일이 많아 무엇부터 시작할지 결정하기 어려운 대학생을 위한 서비스입니다.
사용자가 과제와 시험 준비를 등록하면 임박한 마감·중요도·손대지 않은 기간으로 지금 할 일 하나를 정하고, 구체적인 첫 행동과 5분 타이머를 제공합니다.
할 일을 정리하는 데서 멈추지 않고 실제 시작까지 연결하도록, 선택 과정을 줄이는 사용자 경험을 기획했습니다.

## 파일 역할

- `index.html`: 서비스 소개, 사용법, 체험 화면과 입력창.
- `style.css`: 화면 배치, 색상, 반응형 디자인, 카드 애니메이션.
- `engine.js`: 우선순위, Big 3, 시간 배정 규칙.
- `script.js`: 입력 처리, 화면 갱신, 브라우저 저장과 타이머.
- `icon.svg`: 사이트 아이콘.

## 범위

하루 안의 시간 한 구간에 최대 3개 일을 배정합니다. 계정, 기기 간 동기화, 실제 앱 차단, 여러 날 자동 재계획, 캘린더 연동은 포함하지 않습니다. 마감구조대가 강제로 대신 수행하는 것이 아니라, 사용자가 미리 맡긴 기준에 따라 결정을 대신 내리는 서비스입니다.

수업 제출용 프로토타입이며, 실제 사용자 수·고객 후기·효과 수치를 꾸며 넣지 않았습니다.
